# ghost-pao-shan-ke · 跑山客

🟡 In-Progress

**分类**：扰乱影
**所属段位**：段 1 · 山道
**出现关卡**：[01 · 山](../60-levels/01-shan.md)
**教学概念**：快门冻结 + ISO 基础

## 设定

- **外观**：一个独行的女越野跑者，半透明。穿着旧式登山短裤 + 起球的速干衣，跑鞋磨得很旧，背一个 5L 越野小包。马尾，看不清脸。岁数不明，但姿势是一个跑了很多年的人。光从林间洒下来，落在 ta 身上的斑驳光斑会随 ta 移动一起跑
- **故事一句话**：很多年前一个独行的越野跑者，沿这条山道一遍又一遍循环奔跑，像是要追上什么。**山记得 ta 的速度**
- **朋友与它的关联**：朋友曾经跟着 ta 跑过几次，从来没追上。后来不再追，站在路边看 ta 跑过去——ta 每次会朝朋友点一下头

## 行为

- **AI 模式**：沿一段约 80m 的山道循环奔跑（A 点 → B 点 → A 点，单趟约 12-15s）。**不绕开玩家**——会从玩家身边跑过去，几乎擦肩
- **显形条件**：举相机 + 半按命中跑者身体
- **是否主动靠近玩家**：否（路径固定，与玩家擦肩是路径自然结果，非主动）
- **是否伤害玩家**：否
- **拍照后反应**：
  - **达标**：跑者**站定一帧**，转头朝玩家方向轻轻点头 + 一道光从 ta 身上飘起 + 继续跑但不再循环（跑出视野后这只影该轮不再回来）
  - **糊**：跑者继续循环；朋友笔记本只解锁半页

## 设计意图

- 教学：**快快门冻结快速运动** + **ISO 是亮度补偿手段**——单段同时打通这两个概念
- 教学包揽前段：原 v2.0 林祠静坐者的"半按对焦命中目标"功能在这里顺带教了（玩家要追着跑动的目标半按对焦）
- 叙事呼应"代友登顶"：朋友追过跑山客 / 玩家追过朋友 / 跑山客点头是朋友替你回礼
- ISO 400 解锁伏笔段 2 极光使的 ISO 3200 高位用法（玩家逐段习惯升 ISO）
- 失败成本低（循环重跑），鼓励玩家尝试不同快门档位
