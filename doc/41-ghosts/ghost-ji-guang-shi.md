# ghost-ji-guang-shi · 极光使

🟡 In-Progress

**分类**：扰乱影
**所属段位**：段 2 · 夜脊（夜段）
**出现关卡**：[01 · 山](../60-levels/01-shan.md)
**教学概念**：长曝积累 + ISO 长曝控制 + 防抖

## 设定

- **外观**：一个**仰头望天**的旧时人剪影，几乎完全透明——肉眼几乎看不见，举相机短曝下也看不见。**只有长曝下** ta 身后的夜空才浮现绿紫色的极光带，整个轮廓被极光勾出一道冷光边
- **故事一句话**：很多年前一个为了看一眼极光在这山脊上等了三个夜的旅人。**山记得 ta 的姿势**——仰头望天，一直望
- **朋友与它的关联**：朋友也追过极光。"4s 起步显形，8s 极光成形，15s 才完整。第三夜风停了"

## 行为

- **AI 模式**：仰头静立。几乎不动（< 0.1 m/s 的呼吸级位移）
- **显形条件**：举相机 + 该段夜脊地理范围 + 长曝 ≥ 1s 极光带开始浮现 / ≥ 4s 极光带完整 / ≥ 8s 极光使本体显形
- **是否主动靠近玩家**：否
- **是否伤害玩家**：否
- **拍照后反应**：
  - **达标**：极光带向 ta 身上收束 + ta 缓缓**低头**看一眼玩家方向 + 一道光从 ta 身上飘起 + 淡出
  - **糊（短曝 / 抖动）**：极光不显形，画面里"什么都没有"——玩家以为没东西。回头复看朋友笔记本半页才意识到拍法不对

## 机械数值

| 项 | 值 | 备注 |
|---|---|---|
| `blur_multiplier` | **0.1** | 几乎静止，主要靠累积曝光显形 |
| 移动速度 | ~0 m/s | 仰头静立 |
| 推荐快门 | **4 – 15 s** | < 1s 无显形；4s 极光成形；8s 完整；15s 极光满天 |
| 推荐光圈 | **f/2.8 – f/4** | 极暗夜空大光圈收光 |
| 推荐 ISO | **800 – 3200** | 长曝下夜空亮度，ISO 噪点权衡是本段二级教学 |
| 最低对焦距离 | 5 m | ta 距玩家约 5-10m |
| 亮度偏好 | **极暗** | 无月夜 |
| 占屏比要求 | ≥ 15% | 人 + 极光带占画面较大 |
| 防抖要求 | **必需三脚架点 / 扶岩缝** | 长曝抖动直接糊 |
| **passingScore** | **60** | 显形 + 不糊即可 |

## 设计意图

- 教学三合一：
  1. **长曝积累机制**——短快门下看不见的东西，长曝下显形（继承自 v2.0 雾里残影 + 星灵）
  2. **ISO 高位 + 噪点权衡**——极暗场景必须 ISO 1600+，玩家自己感受噪点（继承自 v2.0 风口山君）
  3. **防抖 / 找支撑点**——长曝下抖动直接糊（继承自 v2.0 星灵）
- 让玩家**真的等 4-15 秒**：节奏的转折点，山路走得急的玩家被迫慢下来
- 视觉冲击：极光是 v2.1 唯一一处"美到一愣"的画面，是顶峰守者云海之前的情感铺垫

## 技术要求（W3 必装）

- **`CAMExposureAccumulator` 接入 `CAMPhotoCapture` 主拍照管线**：当前代码累积器已有但未接入。极光显形机制是这一关唯一依赖真长曝积累的设计
- 长曝期间相机抖动惩罚需放大（玩家应主动找岩缝 / 平台扶稳）
- 极光带渲染：长曝累积下的天空色随曝光时间从黑 → 暗绿 → 绿紫渐变（shader 或后处理）
