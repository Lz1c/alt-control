## W2 · 单点拉通（垂直切片）

**目标**：把段 1 **跑山客**做到 100%，证明所有系统能咬合。段 2 + 段 3 抄它。

任务清单：

- [ ] **影 prefab**：跑山客 GameObject + `CAMMotionBlurSubject` + 跑步动画 + 路径循环 + 显形条件（举相机 + 半按对焦命中）
- [ ] **PhotoEvaluator**：实装 `doc/10-camera-rules.md § 拍照判定` 的 5 维评分；对接 `CAMPhotoCapture` 拍照后回调，输出 0-100 分 + 各维度细分
- [ ] **达标判定**：`passingScore` 60；分数 ≥ 60 → 触发"完整版"笔记本翻页解锁；< 60 → "半页"
- [ ] **笔记本 UI**：实体翻页 / 浮窗 / 取景器叠加（用户决定形态后实装）。一页对应一段 + 一只影
- [ ] **拍照存盘**：`<ProjectRoot>/photo/` 已经有，确认每张拍的都进文件夹（含拍糊）
- [ ] **段 1 完整流程**：玩家从 trailhead 走到山道 → 看到笔记本第 1 页（快门 + ISO 提示）→ 举相机 → 看到跑山客循环跑过 → 半按命中 + 全按拍照 → 看到分数 + 笔记本完整版解锁
- [ ] **观察反转**调味：拍完跑山客后回头肉眼可见的虚影（W2 末尾或 W3）

**退出条件**：段 1 30 秒玩通，影显形 + 拍照 + 达标判定 + 笔记本翻页一连串无 bug。

## W3 · 段 2 + Boss 实装

**目标**：W2 的模板复制到段 2 + 段 3。极光使靠 `CAMExposureAccumulator`，Boss 靠手动对焦 + 大光圈。

任务清单：

- [ ] **`CAMExposureAccumulator` 接入 `CAMPhotoCapture`**（段 2 极光使、Boss 段长曝路径都需要）
- [ ] **段 2 极光使**：仰头静立模型 + 极光带 shader（长曝累积下天空色 → 暗绿 → 绿紫）+ 长曝显形阈值（4s / 8s / 15s）+ 防抖惩罚
- [ ] **段 2 调味**：FakePhoto 注入（边缘多一个未显形剪影）+ 跨段位音源（远方山道脚步声）
- [ ] **段 3 Boss · 山顶守者**：景深 + 手动对焦距离玩法 + 大光圈虚化判定。`PhotoEvaluator` 加权"光圈 + 对焦距离"维度
- [ ] **结尾相册回放**：山顶拍下守者后 → 自动播放本次拍的所有 PNG（按时间序）→ 黑屏 → "献给 ___" → 重玩按钮
- [ ] 拍糊 = 中性结局：进相册回放但缺 Boss 完整版页面

**退出条件**：从主菜单走完整条山路，3 影全显形可拍，相册回放正常播。完整结局 + 中性结局两条线都通。
