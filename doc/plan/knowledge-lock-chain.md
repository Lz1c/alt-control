> **2026-05-11 v2.1 再收紧**：6 段 × 6 概念 → **3 段 × 3 影**，教学曲线浓缩。改这份文档：直接改即可（不算规则层修订），但要在 [`decisions-log.md`](decisions-log.md) 里记一条。

## 总览

游戏开始时玩家**只能用最基础的相机操作**（举起 / 半按对焦 / 全按拍照）。其余参数随登山路径推进**通过朋友的笔记本翻页解锁**——叙事即教学。

| 段 | 路径地形 | 笔记本翻页解锁 | 教什么 | 对应影 |
|---|---|---|---|---|
| 0 | 主菜单 → trailhead | （初始）举相机 + 半按对焦 + 全按拍照 + **中央构图** | 基础操作 + 构图 | （无） |
| 1 | 山道（白天） | **第 1 页**：快门刻度（1/250 → 1/2000）+ ISO 100-800 + 朋友样片 | 快门冻结 + ISO 基础 + 半按命中动目标 | 跑山客 |
| 2 | 夜脊（夜段） | **第 2 页**：慢快门刻度（1/2 → 4s → 15s）+ ISO 800-3200 + 大光圈 f/2.8 + 防抖说明 | 长曝积累 + ISO 长曝控制 + 防抖 | 极光使 |
| 3 | 顶峰（清晨） | **第 3 页**：手动对焦 / 全光圈 / 景深 + 朋友的最后一段话"我想看的是这个" | 景深 + 对焦距离 + 综合 | **Boss · 山顶守者** |

每翻一页 = 玩家相机的某个参数旋钮**从锁定变可调**。这不是 UI 弹窗教学，是**笔记本里手写的字 + 朋友拍的样片**让玩家"看懂"该怎么用。

## 解锁的参数边界（单关全开）

| 参数 | 范围 | 解锁时机 |
|---|---|---|
| 快门 | **15s – 1/2000** | 段 0 = 1/250-1/60 锁；段 1 解锁快档（→ 1/2000）；段 2 解锁慢档（→ 15s） |
| ISO | **100 – 3200** | 段 0 = 100-400 锁；段 1 解锁 → 800；段 2 解锁 → 3200 |
| 光圈 | **f/1.4 – f/16** | 段 0-1 = f/4 固定；段 2 解锁 f/2.8-f/4；段 3 解锁全光圈范围 |
| 测光模式 | 中央重点（log-average） | 全程 |
| 对焦 | 自动半按 / 段 3 解锁手动 | 段 3 解锁手动对焦距离调节 |
| 闪光 | 不解锁 | v2 不做 |
| 曝光补偿 | -2 EV — +2 EV | 全程 |

## 教学目标（玩家通关时必须真的"懂"）

v2.1 把 6 个教学目标压成 **4 个**（合并 + 砍）：

1. **半按对焦 + 取景构图**：把影放在画面中央 70% 区域 + 焦在影身上（trailhead + 段 1 跑山客并教）
2. **快快门冻结**：高速横向运动（跑山客 5-7 m/s）需要 1/500+ 才不糊；同时学 **ISO 是亮度补偿**（段 1）
3. **长曝积累 + 高 ISO + 防抖**：极暗夜空 ≥ 4s 长曝才显形 + ISO 3200 噪点权衡 + 找岩缝当三脚架（段 2 三合一）
4. **景深 / 大光圈虚化 + 手动对焦**：主体清晰背景虚化（Boss 段 3 考察这点）

v2.0 被砍的教学（已合并）：
- ~~慢快门长曝消形~~（雾里残影砍 → 长曝积累概念由极光使承担）
- ~~ISO 800-1600 噪点权衡（独立段位）~~（Boss A 砍 → 噪点教学并入段 2 极光使）

## passingScore 一览

| 影 | passingScore | 备注 |
|---|---|---|
| 跑山客 | 60 | 横向高速，1/500 才能冻结 |
| 极光使 | 60 | 必须长曝 ≥ 4s 显形 + 不糊 |
| **Boss · 山顶守者** | 70 | 综合大考；拍达标 = 完整结局 |
