# 01 · 山（v2 唯一关卡）

🟡 In-Progress

> **2026-05-11 v2.1 再收紧**：6 段山路 + 6 影 → 3 段 + 3 影。详见 [`../plan/rules-revisions.md` 2026-05-11](../plan/rules-revisions.md)。

## 基本信息

- **预计时长**：20-30 分钟
- **结局**：完整 / 中性
- **场景**：Cairn 借用资产（具体山系部分 TBD，见 `plan/open-questions.md`）
- **通关条件**：登顶 + 至少举相机看了一次顶峰守者
- **完整结局判定**：顶峰守者 `passingScore` ≥ 70

## 整体结构

```
主菜单 → trailhead 开场 → 段 1 山道 → 段 2 夜脊 → 段 3 顶峰 → 相册回放 → 黑屏献给字幕 → 重玩按钮
```

线性、单向、不可回头下山（地形挡板 + 软引导）。每段进入时**朋友的笔记本自动浮现一页**，教这一段需要的相机概念 + 解锁该参数旋钮。

## trailhead 开场

- **位置**：山脚营地，Cairn 第一段山路起点
- **触发**：游戏开始进入
- **演出**：
  1. 黑屏 → 主角坐在背包旁，背包里掉出朋友的相机 + 笔记本
  2. UI 提示：捡起相机（E）→ 装备相机
  3. UI 提示：举起相机（Q）→ 进入取景器视角，看到山的轮廓
  4. UI 提示：**中央构图** + **半按对焦（O）** + **全按拍照（P）** → 拍下第 1 张测试照（**进相册存盘**）
  5. 主角内心独白 1 句（文案 TBD：例 "他说山顶能看到云海。我答应过他要拍下来。"）
- **解锁旋钮**：举起相机 / 半按对焦 / 全按拍照
- **解锁参数**：快门 1/250 – 1/60 / ISO 100-400 / 光圈固定 f/4
- **教学**：基础三连（取景 + 半按 + 全按）。原 v2.0 段 1 林祠静坐者的"中央构图"教学并入此处

## 段 1 · 山道（白天）

- **影**：[`ghost-pao-shan-ke`](../41-ghosts/ghost-pao-shan-ke.md)（跑山客）
- **地形**：缓坡林间山道，约 80m 长，斑驳光斑，**跑山客沿这段循环奔跑**
- **建议拍点**：山道中段（跑山客必经路径附近）
- **笔记本第 1 页**：快门冻结 + ISO 基础
  - 朋友的字迹："她跑得很快。我跟过几次，没追上。1/500 才冻得住。慢一档全是糊的。光不够就升 ISO，别怕。"
  - 朋友样片：跑山客糊版（缺角）/ 冻结版（完整）
- **影行为**：跑山客 5-7 m/s 循环奔跑，从玩家身边几乎擦肩跑过。`blur_multiplier` = 2.0；1/500+ 才能冻结
- **解锁参数**：快门上限放到 **1/2000**；ISO 上限放到 **800**
- **passingScore**：60
- **拍达标 → 影点头 + 飘起一道光 + 继续跑但不再循环**
- **拍糊**：跑山客继续循环；笔记本只解锁半页

## 段 2 · 夜脊（夜晚 / 极暗）

- **影**：[`ghost-ji-guang-shi`](../41-ghosts/ghost-ji-guang-shi.md)（极光使）
- **地形**：山脊夜段，无月光（EV 2-3），可见极光带的高纬度天空。山脊上有数个岩缝 / 平台作为天然防抖点
- **建议拍点**：山脊上一处宽平台（可放三脚架）
- **笔记本第 2 页**：长曝积累 + 高 ISO + 防抖
  - 朋友的字迹："4s 起步显形。8s 极光成形。15s 极光满天。风大就一手扶岩缝当三脚架。ISO 千万记得开够——我用过 3200。"
  - 朋友样片：极光使短曝缺角（什么都没有）/ 长曝完整版（极光满天）
- **影行为**：极光使仰头静立，肉眼几乎看不见。≥ 4s 长曝下身后极光带显形，≥ 8s 极光使本体显形
- **解锁参数**：快门下限放到 **15s**；ISO 上限放到 **3200**；光圈范围放到 **f/2.8 - f/4**
- **passingScore**：60
- **技术要求**：`CAMExposureAccumulator` 接入 `CAMPhotoCapture` 拍照管线（W3 实装项）
- **拍达标 → 极光收束飘起 + 极光使低头看玩家一眼 + 淡出**
- **拍糊**：极光不显形，画面空——回看笔记本半页才意识到要长曝

## 段 3 · 顶峰（Boss）

- **影**：[`ghost-shan-ding-shou-zhe`](../41-ghosts/ghost-shan-ding-shou-zhe.md)（山顶守者）
- **地形**：山顶平台，云海铺展在脚下，极远景。**清晨**——经过夜脊一整夜的等待，太阳从云海方向升起
- **建议拍点**：山顶石碑前
- **笔记本第 3 页**：手动对焦 + 大光圈景深
  - 朋友的字迹（最后一段）："这是我想拍的画面。守者站在云海前面，光从他背后来。我想用 f/2.8 + 手动对焦在他的肩膀上，让云海虚化掉。我没拍成。剩下的交给你了。"
  - 朋友样片：山顶守者构图缺角版（焦点不准 / 光圈不对）
- **影行为**：守者背对玩家，立在山顶石碑旁，凝视云海方向。**不动**、不主动转身。**朋友想看到的画面就是从守者背后看出去的云海光**
- **解锁参数**：手动对焦 + 全光圈范围 **f/1.4 – f/16**
- **passingScore**：70
- **拍达标 → 完整结局**：守者缓缓转头，正脸朝向玩家方向（玩家不需要再拍这一帧，叙事自然展开）→ 主角合上相机 → 进入相册回放
- **拍糊 → 中性结局**：守者保持背对，云海一片白光罩住画面 → 主角合上相机 → 进入相册回放

## 相册回放（结尾）

- **触发**：玩家在山顶按下顶峰守者的拍照（无论达标）
- **演出**：
  1. 黑屏 → 相册自动翻页，按时间序播放本次拍的所有 PNG
  2. 每张照片停留 1.5 秒，平移过渡
  3. 完整结局：相册结尾插入顶峰守者转头那张达标照片，停留 4 秒
  4. 中性结局：相册结尾停在一张白光照
  5. 黑屏 → 字幕 "献给 ___ "（朋友名 TBD）
  6. 完整结局：补一段朋友最后一封信文案（TBD）
  7. 字幕滚屏 → 主菜单（"重玩 / 退出"）

## 失败策略（v2 治愈基调）

| 玩家行为 | 反应 |
|---|---|
| 拍糊 | 影短暂淡出 3-5 秒后重新显形 / 跑山客继续循环 / 极光使不显形等待玩家长曝；笔记本只解锁半页 |
| 跳过段 1 跑山客 | 笔记本半页提示"这里你略过了"，可在该段范围内回头补拍 |
| 跳过段 2 极光使 | 同上（极光使所在的夜脊路段范围内可回头） |
| 顶峰守者拍糊 | 进相册回放（中性结局）|
| 关游戏 | 重新开始时从 trailhead 重新走（v2 不做存档续玩）|

**没有**：胶卷消耗 / Game Over 屏 / 重试 prompt / 影追击 / 死亡 / 跌落 / 真扑面 jumpscare（v2.1 撤销）。

## 诡异调味事件清单（SCP 风）

> v2 治愈基调下的**少量恐怖元素**。规则全文见 [`../45-uncanny.md`](../45-uncanny.md)。
> **硬约束**：山顶守者段绝对干净；**v2.1 全片 0 处真扑面**；概率触发，治愈玩家可完全错过。

### trailhead · 计数错乱

- **事件**：玩家拍下第一张测试照后，相册里偶尔多 1 张玩家不记得拍过的照片（一张山的轮廓 / 一张陌生人背影）
- **触发**：5% 概率，每周目最多 1 次
- **类型**：照片诡异 / 计数错乱
- **音效**：无（沉默是关键）

### 段 1 山道 · 观察反转 + 反向掠过

#### a. 观察反转 · 跑山客肉眼可见、相机看不见

- **事件**：玩家拍完跑山客离开几步，回头**用肉眼**瞄一眼山道——还能看到跑山客跑过的虚影（半透明，沿原路径慢动作循环）。**举起相机看**——空了。再放下相机用肉眼看——又有了。来回 1-2 次后停止
- **触发**：拍完跑山客后离开 ≥ 10m + 玩家自然回头，10% 概率
- **类型**：观察反转（**反转 v2 核心机制**）
- **音效**：无；只有玩家自己的呼吸轻一拍
- **设计意图**：让玩家 doubt 自己——"是我看错了吗？是我在举相机时反而看不见？"

#### b. 错位 · 反向跑的跑山客

- **事件**：跑山客循环奔跑数轮后，偶尔出现 1 次**反向跑**的跑山客（从原本跑出的方向跑回来），动作流畅但路径不在循环模型里
- **触发**：玩家在段 1 停留 ≥ 30s，每 30s 检查一次 15% 概率
- **类型**：错位
- **音效**：脚步声节奏比正常的略快一点（或略慢半拍——总之不对）

### 段 2 夜脊 · 照片诡异 + 声音错位

#### a. 照片诡异 · 边缘多一个极光使

- **事件**：玩家拍下极光使的 PNG 后，画面边缘偶尔多出 1 个**没显形**的极光使剪影（实际拍照过程中并没有那个剪影显形）
- **触发**：拍下任一张含极光使的长曝照，20% 概率
- **类型**：照片诡异
- **音效**：无（PNG 已存盘后玩家自己发现）

#### b. 声音错位 · 远方山道的脚步声

- **事件**：玩家在夜脊抬头看天空 ≥ 5s 时，远方传来段 1 山道方向的跑步声（极低音量，节奏不规律）
- **触发**：玩家抬头视角 + 静止 ≥ 5s，15% 概率
- **类型**：声音错位
- **音效**：低音量、低频、远处的跑鞋落地声

### 段 3 顶峰 · **绝对干净**

- 0 处诡异事件
- 0 处 jumpscare
- 这是情感终点。守者背对、转头、合上相机，没有任何不安干扰

## 全片环境层（散布的被跟踪感）

不挂在任何具体段位，全程偶发。控制密度——玩家不应该一直 paranoid。

- **风声混入低语**：风声里偶发听不清的人哼唱 / 远方的"诶"或"啊"，每段 1-2 次，音量极低
- **雪地脚印短现**：玩家偶尔走过的地方，回头看一眼有几个不属于自己的脚印，再回头消失（仅段 2 夜脊出现）
- **远处咳嗽 / 叹气**：玩家在某段静止超过 30s 后，远处偶发一声咳嗽或叹气
